# Ревью перед публичным деплоем

Пока работаем **локально** (`npm start` → http://localhost:3000) — этот отчёт **не трогаем** и не чиним по нему безопасность. Сначала доделываем продукт.

Как только речь зайдёт о **выкладке** (Vercel, публичный URL, `vercel --prod`, прод-ключ) — **сразу остановиться** и пройти чеклист ниже по исходному отчёту:

- оригинал ChatGPT: `docs/reviews/2026-08-18-chatgpt-code-review.txt`
- дата: 18 августа 2026
- архив, который смотрели: `tweak-review.zip` (без секретов)

## Наша оценка отчёта (не слепо повторять HIGH)

Отчёт в целом честный. Главный вывод верный. Часть пунктов раздута.

**Блокеры перед интернетом (реально надо закрыть):**

1. `/api/route` без авторизации и rate limit — чужой может жечь OpenRouter-ключ владельца.
2. Клиент сам присылает system prompt — сервер не должен этому доверять.
3. `parallel=true` = до трёх платных вызовов за один POST. Ограничить на сервере.
4. `/api/weather` без лимита может породить каскад запросов к Open-Meteo (деньги не OpenRouter, но можно завалить функцию).

**Не блокер, не путать с уязвимостью:**

- Цены отелей/рейсов рисует модель — это устройство продукта, не баг.
- Демо-фолбэк при ошибке ИИ уже помечен баннером.
- «Строгая схема JSON модели» не сделает цены настоящими.

**Мелкая логика, можно после деплой-безопасности:** бюджет (если все варианты дороже — не режутся), «редкие дожди» проходят фильтр «без дождей», ISO-даты вроде 2026-02-31.

**Только локальный `npm start`:** раздача исходников `api/*.js`, `--env-file` не на всём Node ≥18, body limit не обрывает сокет.
